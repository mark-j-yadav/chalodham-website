# ChaloDham.in — Hostinger files

## Hostinger pe kaise lagao

1. Is repo se **Code → Download ZIP** karo
2. Zip extract karo
3. Hostinger File Manager → `public_html`
4. Purani `index.php` / `default.php` hatao
5. Is folder ki **saari files** (`index.html`, `assets`, `images`, `.htaccess`) `public_html` ke andar daalo
6. `https://chalodham.in` kholo

WordPress installer mat use karo.
